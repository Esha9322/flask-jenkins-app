🚀 Flask CI/CD Pipeline Project

This project demonstrates a complete CI/CD pipeline using Jenkins, Docker, Docker Hub, GitHub, and AWS EC2.

📌 Why I Created This Project

I wanted to learn how modern DevOps teams automate application deployment. Instead of manually copying files to a server, I built a pipeline that automatically builds and deploys my Flask application whenever I push changes to GitHub.

🛠 Technologies Used

  • Python
  • Flask
  • Git & GitHub
  • Jenkins
  • Docker
  • Docker Hub
  • AWS EC2
  • Linux (Ubuntu)

⚙ CI/CD Pipeline Workflow

  1. Developer pushes code to GitHub
  2. Jenkins clones the repository
  3. Python dependencies are installed
  4. Docker image is built
  5. Image is pushed to Docker Hub
  6. Jenkins connects to AWS EC2 using SSH
  7. EC2 pulls the latest Docker image
  8. Old container is removed
  9. New Docker container is started
  10. Updated application is deployed automatically

✅ Project Outcome

This project helped me understand Continuous Integration and Continuous Deployment (CI/CD), Docker containerization, automated deployments, and cloud application hosting using AWS.
